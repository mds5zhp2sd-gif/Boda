# Invitación boda Sofía y Javi – versión sin envíos externos

Subir `index.html` y `styles.css` a la raíz del repositorio GitHub y activar Settings > Pages > Deploy from a branch > main > /(root).

## Privacidad y funcionamiento
- No se incluye JavaScript ni archivo `script.js`.
- No se incluye formulario de datos ni conexión a Formspree.
- No se descargan fuentes de Google; se usan fuentes del dispositivo.
- Se ha retirado el SVG codificado como data URI de la hoja de estilos.
- Los enlaces a Google Maps se abren solamente cuando el visitante hace clic.
- La confirmación de asistencia debe realizarse directamente con los novios por un canal ya conocido por los invitados.
- Se conserva el dibujo SVG visible en HTML porque es decorativo y no solicita recursos de red.

## Importante
Esta versión no registra confirmaciones automáticamente y no incluye cuenta atrás en vivo. Puede que se vea distinta al original debido a las fuentes locales. Si Zscaler sigue bloqueando, solicita al equipo de seguridad el identificador de regla y el recurso exacto; no intentes eludir el control.
